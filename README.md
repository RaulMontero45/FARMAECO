# FarmaEco

Sample web application with SQL Server database.  

## Setup  
1. Copy `FARMAECO.mdf` to  
   `C:\Program Files\Microsoft SQL Server\MSSQL16.MSSQLSERVER\MSSQL\DATA`  
2. Start Microsoft SQL Server Express.  
3. Unzip `FarmaEcoWebApp.zip`.  
4. Open `FarmaEcoWebApp.sln` in Visual Studio.  
5. Run the project → it will start in your browser.  

## Features  
- Demonstrates integration of SQL Server database with ASP.NET web app  
- Manage **FarmaEco** (sample company) data through a web interface
